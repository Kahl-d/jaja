# resume-tailor: Proof over claims

Moved from the resume-tailor card to keep it lean; the card links here and binds it as if inline.

**Proof over claims.** Everyone lists the popular AI coding tools now. An agent framework, SDK, subagents, hooks,
skills, MCP or orchestration appear only when an artifact bullet backs them, with evidence ids from the matching
corpus folder in `profile/corpus/`, naming the artifact and its scale or outcome. A bare tool list is a defect.
