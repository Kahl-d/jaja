# resume-editor: Finding hygiene

Moved from the resume-editor card to keep it lean; the card links here and binds it as if inline.

**Finding hygiene.** Each finding names one primary rule id (others as "see also"). A keyword on the
must-not-add list is T5 (unevidenced, High) unless the text asserts it as done work, which is T2
(fabricated, Critical); say which, with the line.
